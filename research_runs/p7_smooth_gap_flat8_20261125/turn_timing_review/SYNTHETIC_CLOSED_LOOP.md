# 转向时序的隔离合成对照

`turn_timing_closed_loop.cpp` 用实际 `P6Controller` 的 `flat_nmpc_slqr`、P5 仲裁和命令历史单次提交闭环运行。车辆模型由独立的 5 ms 积分器推进，包含转向和速度的一阶响应及纯延迟。每组 420 个 40 Hz 周期，实时求解预算 8 ms。失效时走同一个合成回退控制器。测试没有启动 ROS 节点。

对照组使用原速度时序，候选组只增加曲率储备和退出弯道的横摆时序代价。两组的参考坐标、初值、模型、求解器、仲裁和硬约束相同。直线和等曲率右弧用于检查修改的作用域。两个镜像变曲率方向用于检查曲率符号。误差按时间统计，也按共同覆盖的 2 cm 空间区间统计，避免某组减速后分母的差别。

三种合成场景描述如下。

- `compound` 在同向弯途中先开再紧，恒定 0.40 m/s 仲裁限制，期望速度 0.385 m/s。第二弯峰值曲率 0.51 m⁻¹，名义横向几何处于转角上限附近。
- `smooth` 将两组的动态仲裁限制在 0.44 m 内从 0.40 降至 0.36 m/s。
- `rapid` 在 0.20 m 内从 0.40 降至 0.33 m/s，用于观察速度和 jerk 约束下的抗突降能力。合成回退可以在不放宽 jerk 的情况下减速跨过动态限制，另统计该期间的速度偏差。试验将合成回退的绝对速度上限设为 0.50 m/s。NMPC 的仲裁限制依然为 0.40 m/s 或该位置更低的动态上限。

从工作区根目录运行，输出每周期 CSV、汇总、二进制 SHA。`--output-dir` 需使用新目录。

```bash
python3 research_runs/p7_smooth_gap_flat8_20261125/turn_timing_review/run_turn_timing_closed_loop.py \
  --cap-profile compound --output-dir "$(mktemp -d)/result"
```

方案评价以配对跟踪误差和实际被选择次数为主。墙钟超时能改变轨迹和后续暖启动，即使直线或等曲率弧的逻辑未激活也可能不逐拍相同。合成回退和定时轮次仅用于软件对照。实车闭环收益需由新方案实际驱动车辆的记录确认。

## 已执行结果

| 合成条件 | 实际观察 |
| --- | --- |
| [同向复合弯，启用 0.025 m/s 储备](synthetic_compound_reserve_025_summary.json) | 同一个基线，左右各 420/420 拍由 NMPC 控制，均无超时或约束超界；每侧激活 59 拍。右弯配对中心误差 RMSE 从 5.719 降至 5.663 mm、P95 从 14.111 降至 14.091 mm、最大仍为 15 mm。收紧段外侧 P95 从 12.849 降至 12.742 mm。命令 jerk RMS 从 0.139 升至 0.146 m/s³。右弯求解 P95 从 4.700 升至 4.858 ms。首拍目标从 0.385 降至 0.379581 m/s；速度指令从下一拍开始变化。 |
| [同向复合弯，启用 0.035 m/s 储备](synthetic_compound_summary.json) | 左右各 420/420 拍由 NMPC 控制、均无超时或约束超界。每侧激活 63 拍，首拍时域目标从 0.385 降到 0.371 m/s。两侧的配对中心误差 RMSE 由 5.734 升至 5.863 mm，P95 从 14.116 降至 14.084 mm，最大误差仍为 15 mm。收紧段外侧误差 P95 从 12.849 降至 12.611 mm，转向速率 RMS 从 0.0702 升至 0.0731 rad/s，命令 jerk RMS 从 0.139 升至 0.182 m/s³。 |
| [同向复合弯，另附横摆先验探索](synthetic_compound_exploratory_release_summary.json) | 先验各激活 4 拍，性能和只启用储备接近。合成试验没有显示该项能消除横摆或改善跟踪。 |
| [平缓动态限速](synthetic_smooth_cap_summary.json) | 更低目标在左右各激活 55 拍，右侧各拍指令相同。两组实测模型速度高于动态限速的拍数均为 145。左侧出现独立的墙钟超时及极小的轨迹差，不能归为策略收益。 |
| [急降动态限速](synthetic_rapid_cap_summary.json) | 左转两组轨迹相同，储备未解决速度与突降上限不相容。右转旧组一个提前发生的墙钟超时改变了后续状态，候选表现较差，无法用该一例把差异归为算法。 |

同向复合弯的直行和等曲率弧对照均未激活改动。0.025 版等曲率弧输出逐拍一致，直行出现一次独立墙钟超时。0.035 版的直行逐拍一致，等曲率弧出现 7 次墙钟超时，最大 37.17 ms。现有合成证据支持提前修改速度目标。0.025 较 0.035 的误差与平顺性折中更好，整体实测改善尚未建立。[右弯逐拍命令与时间](synthetic_compound_right_trace.csv.gz)
