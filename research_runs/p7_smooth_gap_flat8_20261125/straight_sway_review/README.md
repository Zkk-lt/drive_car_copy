# 17:54 实测直线横摆与支持段拟合

本轮采集已封存。6,264 条已提交发布中，2,284 条由 flat8 发出。按同一近直线筛选，16:59 至 17:54 的横误差 P95 为 4.31→4.14 cm，转向速率 RMS 为 0.375→0.338 rad/s，但 IMU 横摆率绝对值 P95 为 0.105→0.119 rad/s。这两轮路况片段与速度分布不同。弯前速度储备实发记录按候选序列核对有 409 拍，17:56:12.875–14.376 和 17:57:38.150–39.650 的记录均未触发该策略。 [实测分段与口径](REAL_SWAY_WINDOWS.md)

17:56:10.799–13.001 处于 TRACK_GOOD，89 拍里 86 拍由 flat8 控制。实发转角范围 −0.178 到 +0.151 rad，最长发布间隔 25.57 ms，随后 CAN 和 IMU 随指令发生了反向。17:56:13.049 的冻结请求中，经过同一姿态传播和路径裁切，接头相对原拟合线偏离 4.36 cm，下游段为 1.16 cm。局部 SLQR 修正量远小于该次波形。近直线切换拍的转向速率 RMS 为 0.509 rad/s，持续同源时为 0.309 rad/s。持续 flat8 的摆动说明主因还在求解使用的几何与实际转向响应的相位差。

支持段拟合在原判直较弱时启用。用路径起点之后 0.38–1.38 m 的已支持位置，以弦方向为切轴拟合二次法向偏移。以同一多项式生成位置、切向和曲率 (κ=2c/(1+(b+2cx)^2)^{3/2}\)。近端连接段不再参与拟合，仍用其几何约束校验修正范围。在可靠直线、明确弯道、前向支持不足、制动参考和末端阶段保留原处理，曲率过渡的速度预瞄优先。

拟合后的车身横摆率用原名义运动学模型从中心航向恢复，和预测的实际转角响应在同一 rollout 中比较。复用原横摆阻尼预算，直线向零横摆率，缓弯跟踪非零的名义横摆率。真实初态、原始安全参考、八个平坦样条变量、命令时序、SLQR 和发布前非线性复验仍在原调用链内。几何单独整形的筛查存在不利样本，最终保留几何与横摆目标配套方案。

157 对实测冻结请求中，两版各有 122 条通过独立全段约束校验，最终候选在两段横摆共 27 帧启用；稳态直线、已抽取绕行和右弯对照未新增启用。冻结回放中首拍转角与预测横摆改善不一致，无法由此证明实车 S 摆下降。 [配对复现](REPLAY.md)
