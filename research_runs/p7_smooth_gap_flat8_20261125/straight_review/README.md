# smooth 直线横摆复盘

数据为同日 16:12:18 和 16:17:01 两轮 smooth 归档，第二轮从 RAM 校验复制。分析使用最终发布的命令来源，CAN 和 IMU 只取发布前已收到的样本。直线分组用局部路径的 0.4–1.4 m 弦形、航向变化和曲率中位数筛选；它并不等于独立的前车轨迹真值，也可能覆盖弯道出口残余横摆。

- 16:12 的直线组有 177 拍，148 拍 flat8；16:17 有 793 拍，536 拍 flat8。第二轮不切换来源的 flat8 中，直线连续强反向 **49/481（10.2%）**，明显弯道 **15/400（3.75%）**。强反向指相邻两次转角变化率异号、绝对值均超过 0.20 rad/s。
- 16:17:36.944 起约一秒连续 **40/40** 条 flat8 发令。参考约 1 m 弦的偏差中位约 **5 mm**，两端切向差约 **0.008 rad**，而转向变化率 RMS **0.426 rad/s**。约 16:17:37.069，发令已转正到 +0.104 rad，CAN 仍近零且为负；约一秒后发令已转负，CAN 仍为 +0.051 rad。两轮直线中的 CAN 运动学横摆率与 IMU 相关均约 **0.94**。接收域命令至反馈的相关峰约 0.45–0.53 s，包含执行器和采样等效相位，不能据此替换模型的纯延迟。
- 这不是单纯的来源交接，也不支持增大 SLQR 局部反馈。第二轮连续记录的 SLQR 局部修正最大不到 **0.0002 rad**。相反，在第二轮开始的 80 条已选中 NMPC 命令中，转向速率连续性权重中位约 **0.00177**，而配置为 **0.05**。原实现把近端相反的曲率尖峰当作真实换弯，压低了平顺性代价。
- 首点切线、曲率由后车实际转角和转角变化率初始化，这对原参考的可执行接续有用。将其局部差分也作为跟踪目标，则把后车正在纠正的运动重新带进 flat8。两轮近直线组 1 m 弦偏差中位只有 **9.3/7.6 mm**，对应重构坐标曲率峰值中位仍为 **0.372/0.688 m⁻¹**。两轮行驶发布间隔最大 **31.29/31.82 ms**，未见反复发布长间隔足以解释上述连续摆动。

新版在 **原始路径限速、速度预瞄、终点参考生成之后**，用至少 1.25 m 的路径点对 flat8 的跟踪参考做几何直线拟合。空间支持须覆盖预测末端后 0.30 m，约等于 0.40 m/s 下一个名义转向响应距离。短尺度切向尖峰不再参与直线判定；实际折弯由重叠弦方向和位置走廊拒绝。平滑混合保留实测线的偏移和方向，不把误差归零，也不改变原路径或曲线的安全速度。近终点、制动或缺少足够空间支持时不启用。延迟模型、SLQR 增益、发布前原几何复验、车辆控制约束及操作授权保持不变。

[历史复算](real_run_summary.md)中，两轮近直线分别命中 **136/160、551/587**，明显弯道均为 **0/551**，目标最大移动 **1.35 cm**。速度、加速度、时间、站坐标及终点未改变。为防止 S 弯的两侧弯折抵消整体航向，也逐对检查相邻长弦的方向变化。完整软件闭环的扰动为合成注入，独立于这些历史原始记录。

[合成闭环对照](noisy_straight_closed_loop.csv)的直线组两侧均为 300 拍。转向二阶差分 RMS **4.44 → 2.51 rad/s²**，车体横摆率 RMS **0.0284 → 0.0256 rad/s**，航向 RMSE **0.0223 → 0.0202 rad**。横向 P95 **4.52 → 4.55 cm**，不能宣称位置跟踪已有提升。圆弯、S 弯和曲率突变的试验组直线修正均未触发；首次合成圆弯对照有 3 次超时，复跑消失，不能从这些少量计时样本推断计算性能。

4 项 C++ 定向回归和 35 项配置测试通过。[私有 ROS 闭环](private_ros.json)选中 94 条 flat8 指令，最长发布间隔 28.95 ms，授权前及到期后为零速。新版已接入[原启动流程](../README.md#原启动入口)，用于后续受监督实车对比。本轮未启动车辆，以上改善只在仿真得到验证。
