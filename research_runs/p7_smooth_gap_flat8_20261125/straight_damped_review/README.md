# 16:44 实测：继续抑制直线横摆

归档 `p7real_20261126T164413_aad90bfa` 的运行二进制通过日志中的 SHA 校验，确认运行上一版直线修正。3,187 条已发布命令中有 1,013 条 flat8。按固定局部几何口径选出 194 个行驶中的近直线周期，其中 158 拍由 flat8 发出。该分组的 IMU 横摆率绝对值 P95 为 0.053 rad/s，跟踪器横偏 P95 为 2.1 cm；没有独立轨迹真值或同速度逐段配对，不能把这两个量和上次不同路段的统计差异直接当成进步幅度。

仍有两种叠加现象：

- 在连续 flat8、直线拟合系数至少 0.8 的 93 拍里，方向变化率 RMS 仍为 0.328 rad/s。16:46:08.633，拟合系数为 1、转向连续性权重为 0.05、横偏约 −1.9 mm；实发 +0.119 rad、CAN +0.105 rad、IMU +0.071 rad/s。此拍还存在航向修正需求，单拍不能判定过冲，但足以否定「摆动只在直线修正未生效时出现」。近直线段局部 SLQR 修正量 P95 约 0.000045 rad，远小于转向指令。
- 近直线在换控制源时的强反向为 9/23，持续同源为 11/171。部分回退由测得速度超过当时的动态安全上限触发，这类约束不能为消除摆动而放宽。近直线发布间隔最大 26.99 ms，不能把该组小幅摆动归因于超时。

上一版的软项主要惩罚指令转角变化率的变化。本版在 flat8 原跟踪误差上增加预测横摆率代价 `d × ω²`，其中 `ω = g_y v tan(δ)/L + r_y` 由同一个延迟执行器模型和已发命令队列预测。不从 IMU 差分或局部曲率尖峰构造目标，不改变反馈增益，也不在发布后压转角。使用直线拟合系数的平滑门控：0.55 以下关闭，0.95 以上到配置值；曲线、末端、制动继续用原安全及控制逻辑。代价进入完整 rollout 和解析 Gauss–Newton，八个平坦决策变量不变。

[仿真对照](damping_summary.csv)固定同一组直线路径扰动、名义模型、限速和 8 ms 预算。直线权重 0/1/2 各做 300 拍，均选 flat8。权重 2.0 相对关闭横摆阻尼时，IMU 对应的模型横摆率 RMS 从 **0.02454 降至 0.02199 rad/s**，转角二阶差分 RMS 从 **1.713 降至 1.446 rad/s²**，横向 P95 **4.518 → 4.517 cm**，RMSE **1.696 → 1.731 cm**。权重 1.0 虽压低了横摆率，却使转角二阶差分变大，因此不选。圆弯、S 弯和曲率阶跃没有启用零横摆代价；这些运行的求解超时随调度而变，存在回退时不将性能差异归给这项关闭的代价。所有配对组没有检测到指令和模型车辆约束违规。

[反向顺序复测](DAMPING_AB.md)中，权重 2.0 的直线组有四次求解超时，横摆率 RMS 仍降低约 11%，但转角二阶差分 RMS 从 1.713 升到 2.023 rad/s²。这一结果不支持在有超时回退时也能保证转向更平顺。

36 项试跑配置测试和 4 项 C++ 回归通过。[私有 ROS 模拟闭环](private_ros.json)选中 93 条 flat8 命令，99 条有效候选记录到阻尼，最长发布间隔 **30.04 ms**，没有授权及授权过期时保持零速。实车横摆、横偏和弯道表现仍需下一轮配对验证。下一轮先比较连续 flat8 和切换拍，不用只看整轮均值。
